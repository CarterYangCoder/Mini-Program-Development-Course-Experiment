# Lab 6 - 图片分享社区

本项目完成了实验要求的图片分享社区小程序，已在 `miniprogram/app.js` 中配置云开发环境：`cloudbase-d4go8irco7551d927`。

## 已实现功能

- 首页按上传时间倒序显示全部图片卡片；点击头像进入个人主页，点击图片进入详情页。
- 用户授权头像和昵称后，从相册或相机上传图片到云存储，并将图片、作者和日期写入数据库。
- 个人主页显示指定用户发布的图片；上传页显示当前用户的上传历史。
- 详情页支持保存到手机相册、分享给好友和全屏预览。
- `cloudfunctions/getOpenId` 云函数安全获取当前用户的 OpenID。
- 首页提供作品/作者/主题搜索、主题筛选和本地收藏；收藏仅保存在当前设备。
- 发布作品时可补充标题、故事和主题标签；详情页与个人主页会展示这些作品信息。

## 首次运行

1. 在微信开发者工具导入本项目，并确认使用的云开发环境是 `cloudbase-d4go8irco7551d927`。
2. 打开云开发控制台，在数据库中新建集合 `photos`；权限设为“所有用户可读，仅创建者及管理员可写”。
3. 在 `cloudfunctions/getOpenId` 上右键，选择“上传并部署：云端安装依赖”。
4. 编译小程序。从首页点击“上传图片”，授权头像昵称后即可上传并验证全部流程。

> 云函数首次部署前，上传页会提示“云函数未就绪”，这是为了避免没有 OpenID 时写入错误的上传记录。
