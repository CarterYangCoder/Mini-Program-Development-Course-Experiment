## 一、实验内容

本实验使用 HarmonyOS ArkUI 与 ArkTS 开发多功能计算器，包含基础计算、科学计算、函数图像、数学与物理公式、汇率换算和设置等功能。

主要功能：

1. 支持加减乘除、百分数、正负号、退格、清零和记忆运算；
2. 支持计算历史记录，最多保留最近八条；
3. 支持幂、开方、阶乘、对数、指数、三角函数和双曲函数；
4. 支持弧度/角度切换、圆周率、随机数、科学计数法和括号；
5. 支持函数表达式绘图、公式代入计算和实时汇率换算；
6. 支持按键提示音、触感反馈、小数位数、百分数模式和汇率更新设置。

## 二、实验步骤与关键实现

### 1. 项目初始化与页面配置

项目采用 HarmonyOS Stage 模型，主要文件包括 Index.ets、DecimalMath.ets、ExchangeRate.ets、FormulaCalculator.ets、FunctionGraph.ets 和 SettingsPage.ets。主页面负责计算器状态与模式切换，各功能拆分为独立组件。

### 2. 基础计算与高精度运算

Index.ets 使用当前值、左操作数和待执行运算符维护输入状态。DecimalMath.ets 将数字拆分为符号、数字字符串和小数位，使用字符串逐位完成加减乘除，减少浮点误差，并处理科学计数法、负数、除零和非法输入。

### 3. 科学计算

科学模式支持幂运算、开方、阶乘、对数、指数、三角函数、双曲函数、括号、π、EE 和 Rand，并可切换弧度与角度。对数、开方和阶乘会进行定义域检查，非法结果显示“错误”。

### 4. 函数图像与公式库

FunctionGraph.ets 对表达式进行采样，将数学坐标转换为画布坐标后绘制曲线，并支持缩放。FormulaCalculator.ets 提供数学公式和物理公式，用户选择公式并输入参数后进行计算。

### 5. 汇率换算

ExchangeRate.ets 通过 HTTP 请求 Frankfurter 参考汇率服务，成功时显示汇率日期；网络不可用时使用内置参考汇率，保证离线情况下仍可完成换算。

### 6. 界面设计与设置

页面使用 ArkUI 声明式组件、状态变量、Column/Row/Stack 布局和横竖屏适配。设置页支持按键提示音、触感反馈、百分数模式、结果小数位数和自动更新汇率。

## 四、问题总结与体会

浮点数直接计算容易产生精度误差，因此项目使用字符串级十进制运算。科学函数存在不同定义域，执行前必须校验输入。汇率服务属于外部依赖，使用内置参考数据进行离线回退。通过将汇率、公式、函数图像和设置拆分为组件，主页面逻辑更加清晰，也便于后续维护。
