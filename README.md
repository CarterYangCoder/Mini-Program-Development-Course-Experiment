# 高校新闻网微信小程序

依据 `lab3.pdf` 搭建的原生微信小程序，包含首页、新闻详情和个人中心三个页面。

## 功能

- 首页三图自动轮播、本地新闻列表与详情跳转
- 新闻详情展示及本地收藏/取消收藏
- 个人中心登录、头像昵称展示、收藏列表和收藏详情跳转
- 首页/我的 tabBar 切换

## 运行

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本文件夹。
3. 当前配置使用 `touristappid`，可直接体验；需要真机功能时，在 `project.config.json` 中换成自己的小程序 AppID。
4. 点击“编译”即可预览。

新闻图片已放在 `images` 目录，不依赖外部图片服务器。用户资料授权不可用或被拒绝时，可使用弹窗中的体验身份继续验证收藏流程。
