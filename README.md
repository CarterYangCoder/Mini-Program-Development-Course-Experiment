## 开发环境

- 开发工具：微信开发者工具
- 技术栈：微信小程序原生开发（WXML / WXSS / JS）
- 渲染引擎：Skyline

## 目录结构

```
├── lab1/   # 实验1：第一个微信小程序（Hello World 主题切换）
├── lab2/   # 实验2：名片小程序（个人介绍页）
├── lab3/   # 实验3：高校新闻网微信小程序（海大新闻）
```

## 使用方式

每个 `labN` 目录均为一个完整的微信小程序项目，使用微信开发者工具「导入项目」选择对应目录即可打开运行。
