# 实验4：微信小程序推箱子游戏

中国海洋大学 26 夏《移动软件开发》课程实验四。项目使用原生微信小程序框架和 Canvas 2D 实现一款完整的推箱子益智游戏。

## 功能特性

- 四个 8×8 推箱子关卡，使用二维数组管理地图；
- Canvas 2D 高清绘制冰面、石墙、目标、箱子和玩家；
- 支持方向键和棋盘滑动两种控制方式；
- 包含碰撞检测、推箱规则、平滑动画、震动反馈和撤销操作；
- 支持重新开始、关卡切换、通关判定和个人最佳成绩；
- 玩家可选择头像、填写昵称并登录；
- 不同玩家的最佳成绩和游戏历史使用本地缓存隔离；
- 历史页展示通关关卡、步数、时间和新纪录状态；
- 使用渐变、卡片、进度条和响应式布局优化游戏界面。

## 项目结构

```text
lab4/
├─ pages/
│  ├─ start/           # 启动加载、头像昵称与登录
│  ├─ index/           # 玩家信息、数据概览与关卡选择
│  ├─ game/            # Canvas 游戏、移动、动画与通关逻辑
│  └─ history/         # 玩家游戏历史与统计
├─ images/
│  ├─ icons/           # 游戏地图与角色素材
│  └─ level01~04.png   # 四个关卡预览图
├─ utils/
│  ├─ data.js          # 四个关卡的二维数组地图
│  └─ auth.js          # 登录、最佳成绩和历史记录工具
├─ Lab4.md             # 完整实验报告
├─ app.json            # 全局页面与导航配置
└─ project.config.json # 微信开发者工具配置
```

## 运行方式

1. 打开微信开发者工具；
2. 选择“导入项目”；
3. 将本目录 `lab4` 作为项目目录；
4. 使用 `project.config.json` 中的 AppID，或替换为自己的小程序 AppID；
5. 点击“编译”运行。

完整实现过程、关键代码与测试结果见 [Lab4.md](./Lab4.md)。
