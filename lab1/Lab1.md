## 一、实验内容

**1. 实验目的**

熟悉微信开发者工具的基本操作，理解微信小程序的项目结构与文件组成，掌握页面（WXML / WXSS / JS / JSON）的开发流程，并在此基础上完成一个带有交互效果的 "Hello World" 小程序。

**2. 实验环境**

- 操作系统：Windows 11
- 开发工具：微信开发者工具（使用 Skyline 渲染引擎、glass-easel 组件框架）
- 项目名称：狼崽001

**3. 实验步骤**

（1）**创建项目，认识项目结构**：新建小程序项目后，观察并理解各个文件的作用：

- `app.json`：全局配置，注册页面路径，本项目注册了 `pages/index/index`，并开启了 Skyline 渲染与自定义导航栏；
- `app.js`：小程序入口逻辑文件；
- `app.wxss`：全局样式；
- `pages/index/`：页面目录，由 `index.wxml`（结构）、`index.wxss`（样式）、`index.js`（逻辑）、`index.json`（页面配置）四个文件组成。

（2）**实现 Hello World 页面**：在 `index.wxml` 中输出问候文本，通过自定义 `navigation-bar` 将导航栏标题设为"狼崽001"，页面正常编译运行。

（3）**美化页面布局**：为了让页面不再单调，采用以下设计：

- 整页使用 `linear-gradient` 渐变背景（粉紫系渐变 `#ff9a76 → #fbc2eb → #ffd1a9`）；
- 页面使用 flex 弹性布局居中，内容按 emoji → 标题 → 卡片 → 按钮的顺序排列；
- 语录放入半透明白色圆角卡片中，按钮设计为白色胶囊形状，并添加 `:active` 按压反馈（缩放/变亮）。

（4）**增加交互功能**：在 `index.js` 中定义数据与事件处理：

- 点击切换按钮，在"女生（🌸）"与"男生（🐺）"两套主题间切换。两套主题分别定义了 `wording`、`emoji` 和 5 条语录，切换时通过 `setData` 一次性更新页面数据，背景色也随主题变为暖色系（女生）或冷色系（男生）；
- 点击语录卡片，按顺序轮换显示下一条语录，使用取模运算实现循环；
- 所有语录统一以感叹号结尾，并区分中英文标点：中文句子使用全角"！"，英文句子使用半角"!"。

（5）**修复布局问题**：预览后发现背景只铺满上半屏、下方留白，且卡片内文字重叠。通过排查发现是 `scroll-view` 的高度未正确继承导致的，修复方案为：给 `page` 设置 `height: 100vh` 并开启 flex 纵向布局，`scroll-view` 与内部 `.page` 容器统一设置 `height: 100%`，同时为各元素明确设置 `margin` 间距、将文字设为块级显示，最终背景铺满全屏且各元素排列清晰、互不重叠。

**4. 实验结果**

小程序可以正常编译运行。打开后展示渐变背景下的 "Hello girl!" 标题与一条暖心语录；点击切换按钮，页面整体变为冷色蓝青渐变，文案切换为 "Hello boy!"，emoji 由 🌸 变为 🐺，语录也整套替换；点击语录卡片可循环查看当前主题下的 5 条语录。交互流畅，页面观感舒适。

关键代码如下（切换主题的核心逻辑）：

```javascript
onSwitch: function() {
  const key = this.data.isGirl ? 'boy' : 'girl'
  const theme = THEMES[key]
  this.setData({
    isGirl: key === 'girl',
    wording: theme.wording,
    emoji: theme.emoji,
    phrases: theme.phrases,
    phrase: theme.phrases[0],
    phraseIndex: 0
  })
}
```

## 二、问题总结与体会

**1. 遇到的问题与解决**

- **问题一：背景只铺了上半屏，下半部分白白一片。** 起初页面容器使用 `min-height: 100%`，但嵌套在 `scroll-view` 中时高度继承失效。解决方法是让 `page` 撑满视口（`height: 100vh` + flex），`scroll-view` 和内部容器都显式设为 `height: 100%`，渐变即可铺满全屏。
- **问题二：卡片内文字与按钮挤在一起。** 原因是各元素没有明确的间距。解决方法是统一用 `margin` 明确每个块的外边距（emoji 下 40rpx、标题下 56rpx、卡片内容之间 28rpx、按钮上方 64rpx），并把文字设为块级元素保证上下排列。
- **问题三：页面空白太多，显得空旷。** 通过居中布局、放大 emoji（200rpx）、新增语录卡片承载内容，让页面内容更饱满。
- **问题四：中英文标点混用。** 中文语录误用半角感叹号，后统一为中文用全角"！"、英文用半角"!"，保证规范。

**2. 收获与体会**

- 通过本次实验，我真正理解了小程序"一个页面四个文件"的组织方式，以及 `app.json` 全局注册页面的流程；
- 掌握了 `setData` 驱动视图更新的机制——凡是界面上要变化的文字、颜色，都必须放到 `data` 中，再通过 `setData` 修改，直接改局部变量页面是不会变的；
- 学会了用"数据驱动"的思路做主题切换：把女生/男生两套主题抽成配置对象，一套代码即可切换整套文案、emoji 和背景色，代码简洁且易扩展；
- 对 flex 布局、`rpx` 响应式单位、渐变背景、`:active` 按压反馈等 CSS 技能有了实际运用，认识到布局类问题往往出在"高度继承"上，排查时要从父容器一层层找。
